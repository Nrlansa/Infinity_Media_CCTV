#  Infinity Media - CCTV Solution Landing Page 

A high-performance landing page architecture built with Laravel 12, designed for efficiency and scalability. This project serves as the digital foundation for Infinity Media's CCTV service promotion, focusing on a clean, modular, and maintainable codebase.
A professional landing page project for **CV. Infinity Media**, demonstrating the seamless integration of a custom UI template into the **Laravel 12 framework**. 

## Technical Implementation
- **Modular Architecture:** Utilized Laravel Blade Components to create reusable UI elements, ensuring clean code and easy maintenance.
- **Asset Management:** Implemented an organized asset structure to ensure fast load times and logical file management.
- **Frontend Framework:** Leveraged Bootstrap 5 for a responsive, mobile-first, and professional UI/UX design.
- **Performance-Oriented:** Developed with a focus on code structure and maintainability for future feature expansions.

## Project Highlights
- **Framework:** Laravel 12.45.1
- **Architecture:** Modular Blade Components (Hasil slicing mandiri).
- **Frontend:** Berbasis template **Securex** (Bootstrap 5).
- **Purpose:** Media promosi digital dan publikasi layanan CCTV.
